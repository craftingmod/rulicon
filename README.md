# RuliCon

![UI](./docs/ui.webp)

특정 사이트에서 불편하게 디자인 된 아이콘 선택기를 개선합니다.

## 기능

- 가상 스크롤로 실제로 보이는 이미지 렌더링으로 성능 향상
- (로컬) 즐겨찾기, 최근 사용으로 아이콘 우선 정렬 및 확인
- 현대적인 UI
- 독단적인 통보로 편집하기 불가능에 가까워진 100개 넘는 아이콘의 간편 편집 & 사용 지원
- 모바일 & 데스크톱 모두 지원

## 설치

- Chrome 확장: 빌드는 가능하지만 심사 중이여서 수동 설치만 가능
- 유저스크립트: [설치](https://cdn.jsdelivr.net/gh/craftingmod/rulicon@userscript/rulicon.user.js) - 애드가드 혹은 Tampermonkey가 필요합니다.
